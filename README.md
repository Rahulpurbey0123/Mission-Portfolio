# Rahul Kumar Purbey — Personal Portfolio Website

An ultra-modern, production-ready, dark-themed personal portfolio website for **Rahul Kumar Purbey**, Computer Science Engineering student at **SRM Institute of Science and Technology**, AI & Machine Learning Enthusiast, and Full Stack Developer.

Designed with inspiration from **Vercel, Linear, Apple, OpenAI, and GitHub**.

---

## 🚀 Features & Design Highlights

- **Aesthetic**: Premium 2026 Dark Mode with Glassmorphism, custom Slate background (`#0f172a`), glowing accents (`#3b82f6` & `#06b6d4`), subtle backdrop blurs, and smooth cubic-bezier transitions.
- **Hero Section**: Custom canvas-rendered particle network background, dynamic typing role rotator, floating tech stats cards, and avatar glow effects.
- **About Me**: Professional biography, interactive stat counter triggers, and core areas of interest tags.
- **Education Timeline**: Vertical glassmorphism timeline detailing SRM IST, Sagarmatha English Boarding School, and Times School.
- **Skills Grid**: Categorized skill cards covering Programming (Python, Java, C, C++), AI & ML (RAG, NLP, Whisper, XGBoost), Frontend, Backend, Databases, and Engineering Tools.
- **Experience**: Detailed professional timeline for Data Science Internship at Artistic Impression.
- **Featured Projects**: Card showcases with hover zoom overlays, technical feature bullet points, and live step-by-step RAG pipeline flow visualization.
- **Certifications & Coursework**: Sleek grid cards for Data Science, Data Engineering, ML, AI, and CS core subjects.
- **GitHub Stats & Activity**: Dynamic integration of GitHub stats cards and top languages.
- **Contact Form & Details**: Working interactive contact form with instant validation, current location, email, and social handles.
- **Responsive**: Fully optimized across Desktop, Laptop, Tablet, and Mobile screens with mobile drawer navigation.

---

## 🛠️ Tech Stack

- **Structure**: HTML5 (Semantic, SEO Optimized, Accessible ARIA)
- **Styling**: CSS3 (Vanilla CSS Custom Properties, Glassmorphism, Responsive Media Queries)
- **Scripting**: Vanilla JavaScript (ES6+, Canvas Particles, Scroll Progress, IntersectionObserver)
- **Libraries & Icons**:
  - [Font Awesome 6](https://fontawesome.com)
  - [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
  - [Typed.js](https://mattboldt.com/demos/typed-js/)

## 🌐 Deploying to GitHub Pages

1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/RahulKumarPurbey/RahulKumarPurbey.github.io.git
   git push -u origin main
   ```
2. Navigate to **Settings** > **Pages** in your GitHub repository.
3. Select `main` branch and `/ (root)` folder, then click **Save**.
4. Your website will be live at `https://rahulkumarpurbey.github.io/`!
